# 2026-11-18: Second Shift review findings fixed (REVIEW-1118)

Vivienne's overnight review of seven merged PRs found 12 problems. All are dealt with.

- **Failing tests are never silently cut.** A run with more than 12 failing tests says how many failed in total and how many are not listed. Failures in every part of a job's log are counted, not only the first part that had any.
- **The log reader is now tested on real logs**, not imitations: a real Windows (dotnet) failure from the windows-door PC runner, and real vitest, node, pytest and go output. That uncovered five ways the reasons came out wrong (extra bookkeeping lines, a missed node format, pytest's tally instead of its reason, go's verbose order). All fixed.
- **"Archived repository" is matched only on GitHub's exact message**, so a different 403 problem is never mistaken for it.
- **A workspace closed when Dokploy was retired** now says its clean-up was done by hand by the server's owner, not checked by the service.
- **Claims in earlier PR cards now carry evidence**: today's live reads of the server status and the sweep timer, and the files where the owner-only Git rule lives.
- **Long pull-request diffs can be read in pages** (Vivienne's request): no part of a big diff is lost any more, and a diff that changes mid-read is refused instead of mixed.
- **Two open questions answered**: the "operator" mark can only be set by the server itself; and a repeat after a different tool changed the same thing is deliberately still a replay (labelled as one), because sending it again could duplicate a create.
