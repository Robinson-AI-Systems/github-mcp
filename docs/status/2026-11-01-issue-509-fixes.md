# 2026-11-01 — Issue #509: attach unreachable, dispose 401

Reproduced live on the released server (workspace `job_343a808fc7b17a6c`, small runtime): the allocation reached
`allocated`, but the `coding` container had exited (0) immediately while `broker` was healthy and `ingress` stayed in
`health: starting` — its health check forwards to the dead runtime — so the allocation address never routed. Cause: the
runtime's first heartbeat goes to `http://broker:3000/v1/authority`, the broker was not listening yet, and any heartbeat
failure without a prior lease stopped the runtime. Dispose then failed on `dockerVolume.getVolumeConfig` 401.

Fixed in this PR (see the dated PLAY-1 card section). Live re-test follows the release.
