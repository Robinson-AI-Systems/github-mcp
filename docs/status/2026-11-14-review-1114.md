# Second Shift review fixes (2026-11-14)

The overnight review of #633–#636 found these; fixed here:

- **Who failed is named.** A fault in this server's own code is now `internal_error` (and in the write layer `uncertain`, because it may have stopped part-way). It is never "the request was refused". This server's own refusals are `invalid_request`, not `provider_rejected`; GitHub's own refusals keep `provider_rejected`. The rule lives in `src/core/error-origin.js`.
- **Refusal receipts never vanish.** A failed save is logged, the broker's answer carries `receipts: {saved, error}`, and the push hook tells the person the exception flow won't find that push yet.
