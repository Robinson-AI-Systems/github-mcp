# 2026-11-01 — PUB-8: owner removes a person by identity

- **Built (PR #518, branch `ai/claude/pub-8-identity-removal`):** owner-only tool `github_tenant_remove`. Preview first;
  with `confirm: true` it revokes the person's stored GitHub sign-ins at GitHub, removes everything stored for them
  through one SQL removal core (every shared row with their tenant id, their own namespace, device pointers, identity;
  managed Playground allocations handed to the regular sweep), and reads back that nothing is left. Refuses the owner's
  own identity without `includeOwnIdentity: true`, shared spaces and unknown people. Listed and callable only on the
  owner's own direct connection.
- **Same core for people:** the existing "Delete my data" page and owner setup page now run the same core.
- **Verified:** `tests/unit/pub-8-tenant-remove.test.js` (write contract through every door, gate, refusals) and
  `tests/db/pub-8-tenant-removal.test.js` (real PostgreSQL, every table). Not run against real tenants or live.
- **Next:** after the daily release, a deployed acceptance row may preview (dryRun) a removal of a scratch person.
