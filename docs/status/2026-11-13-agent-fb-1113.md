# Agent feedback fixes (2026-11-13)

- **Scanner exceptions:** add or remove single exceptions with `addSuppressions` / `removeSuppressions`. Replacing the list can no longer silently drop exceptions. Every refusal says exactly what is missing.
- **Errors:** this server's own refusals read as `invalid_request` with the full reason, never as "GitHub could not be reached".
- **CI logs:** `github_actions_get_job_log` can `search` a log and return each match with context and a place to read on from.
- **Merging:** a red check is named (`failed_checks`), with the tool that says why.
