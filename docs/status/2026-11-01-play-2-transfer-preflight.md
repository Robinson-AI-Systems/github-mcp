`tools/playground-device/measure-workspace.mjs` performs read-only bounded scanning of a local native Git workspace root or ordinary Git checkout. It reports Git HEAD, uncommitted status, worker generation and state if available, raw size, file/path count, symlinks, generated/Git metadata categories, largest file, metadata digest and scan duration, with no names, contents, keys or storage mutation in output. It mirrors the existing `workers/native-git/snapshot.js` limit: 100 MiB raw files / 100,000 path entries / zero symlinks, excluding only the three snapshot lock/marker entries. The result distinguishes a repository-only proxy from a genuine native workspace and never claims an encrypted transfer succeeded.
