# 2026-11-19: built-in machine management (MACHINES-1)

- **One place for machines**: `github_machines` lists every Git machine and Playground computer; `github_machine_change`
  adds a Git machine (its address is checked first), removes one, switches one off or on, pairs a new computer or removes one.
- **Still safe**: machines added this way are kept in a list signed by the server, so changing the database alone cannot add one.
- **Nothing stays "revocation pending" forever**: a removed computer that never checks in again closes after 7 days,
  or at once when it is marked gone (the Workshop).
