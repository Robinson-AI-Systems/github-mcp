# Service status

Status: Draft written by an AI agent for the owner (PUB-7, 2026-11-01). Not yet approved by the owner and not yet reviewed by a lawyer.

**What this page is.** This page shows how Robinson GitHub MCP is set up right now: whether new people can sign in, and which version of the service is running. It is not an uptime monitor and it is not a list of past incidents. Nothing on this page is measured live; it is read from the service's own settings when you open it.

## When something is not working
- **GitHub itself:** GitHub has its own outages. Check GitHub's public status page (githubstatus.com) first.
- **Your assistant:** your assistant's provider runs its own service with its own status page.
- **Busy or paused:** if the service is busy it asks your assistant to wait and try again. New sign-ups can be paused by the owner, or automatically when the estimated monthly hosting cost reaches its limit; people who already have a connection keep working.
- **Usage limits:** the free use limits are listed on the Limits page (/limits).

## Report a problem
Email [support email]. Tell us which assistant you use, what you expected, what happened and roughly when. Never send passwords, tokens or private keys. Security problems: see the Security page (/security).
