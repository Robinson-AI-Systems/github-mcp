Add this computer to your Playground

Your AI assistant can run builds and tests on computers you own. This setup turns this PC into one of those computers. It only makes outbound connections — no open ports, no public address — and it runs only your own work.

What happens

  1. Setup checks this PC (about a minute).
  2. Windows asks once for administrator permission.
  3. Setup installs its own private workspace on this PC — a separate Linux area with its own Docker. Anything already here (your files, Docker Desktop, other Linux installs) is left exactly as it is.
  4. You approve this computer on your My connection page — that is the second and last decision.

Total: about 5 minutes of your attention. If Windows needs one restart, setup resumes by itself when you sign back in.

Download setup

Run the downloaded file and follow the screens. Windows may warn you the file is not signed yet — choose “More info”, then “Run anyway”. Revoking the computer later, on My connection, stops and deletes its runtimes.
